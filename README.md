# Named Entity Recognition (NER) Project

## Overview
This project is a Data Science and NLP-based Named Entity Recognition (NER) system used to extract entities from text and PDF documents.

## Files Included
- `extract_text.py` – Extract text from files
- `pdf to text.py` – Convert PDF into text
- `pre_processing.py` – Clean and preprocess data
- `Tokens.py` / `tokens.py` – Token generation
- `Validation.py` – Validate extracted entities
- `product_extraction.py` – Extract product-related entities
- `extract_table.py` – Extract table data
- `extract_Miscellaneous.py` – Extract miscellaneous entities
- `INCO_dataset.py` – Dataset handling

## Technologies
- Python
- NLP
- Machine Learning
- Pandas
- spaCy / NLTK
